# hxyfront-62010 余压回收与阀件隔离复充台

面向潜水店的余压回收与阀件隔离复充工作台(React + Vite + TypeScript)。

## 业务规则

- **回收登记**:每瓶回收前登记余压、介质与阀门密封结果。
- **隔离判定**:阀门密封异常,或余压低于充填下限(30bar)的气瓶只进隔离清单,不占充填位(共 6 个)。
- **更正联动**:回收记录更正后,依赖它的未完成充填立即冻结;已签收记录保留,但标记"受更正影响";更正后命中隔离条件的,记录转入隔离清单。
- **隔离解除**:必须换人复检(复检人 ≠ 原登记人)且复测合格(密封合格、余压不低于下限)才能恢复;解除后气瓶重新排队、占用充填位,被冻结的充填一并恢复。
- **一致性**:队列、统计全部由同一份状态推导,操作即写入 localStorage,刷新后保持一致。

## 分层结构

```
src/
  domain/      规则层(纯函数,不依赖界面与存储)
    types.ts       实体与状态类型
    constants.ts   充填下限、充填位数等业务常量
    rules.ts       登记/更正/签收/冻结/解冻/复检解除/统计
    seed.ts        演示数据
  data/        存储层
    store.ts       localStorage 读写与重置
    useStation.ts  界面 ↔ 规则 ↔ 存储 的状态桥
  ui/          界面层(只负责渲染与采集输入)
    App 子组件:登记表单、待充填队列、隔离清单、回收台账、签收记录、操作日志
```
