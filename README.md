# hxyfront-62010 余压回收与阀件隔离复充台

在原有潜水气瓶充填页面上改造的复充台前端，面向潜水店回收—隔离—复充流程。

## 业务规则

- **回收登记**：每瓶回收前登记余压、介质、阀门密封结果与登记人。
- **隔离判定**：密封异常或余压低于充填下限（30bar）的气瓶只进隔离清单，不占充填位。
- **更正级联**：回收记录更正后，依赖它的未完成充填立即冻结；已签收记录保留但标记受影响；更正后复评仍不合格的转入隔离并释放充填位。
- **隔离解除**：须换人复检（复检人 ≠ 原登记人）且复测合格（密封合格且余压达标）才能恢复，复测值回写后气瓶重新占充填位。

## 代码结构（规则 / 存储 / 界面分离）

- `src/domain/types.ts` — 领域模型（回收记录、充填任务、隔离条目）
- `src/domain/rules.ts` — 纯函数业务规则：隔离判定、更正级联、复检解除、统计汇总
- `src/data/store.ts` — localStorage 持久化与种子数据（队列、统计刷新后一致）
- `src/hooks/useStation.ts` — 状态桥接：所有变更经规则层计算后写入存储
- `src/components/` — 界面：回收登记、充填队列、隔离清单、回收台账、签收记录

## 技术栈
